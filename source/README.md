# source: مصدر النموذج الأولي

`../index.html` يُبنى من هذه الأجزاء (HTML + CSS + JavaScript في ملف واحد، بلا مكتبات):

| الملف | محتواه |
| --- | --- |
| `part1.html` | الهيكل والتنسيق |
| `part2.js`, `part3.js` | القواعد اللغوية والتصنيف وتحليل الملفات |
| `partsample.js` | البيانات المجمّعة المضمّنة (قوقل ماب، تيك توك، X) |
| `part4s.js` | شاشة «ماذا حصل؟» والرسوم البيانية |
| `part5s.js`, `part6s.js`, `part7s.js` | التوصيات والتقرير والمساعد |

```
python3 build.py        # ينتج advisor_simple.html (يطابق ../index.html)
./run-tests.sh          # يبني ويشغّل اختبارات المتصفح (يحتاج Node وPlaywright)
```

الاختبارات في `tests/`: صحة التصنيف، الفعاليات الجديدة ورفع الملفات، الجوال بلا تمدد أفقي، التقرير، والرسمان البيانيان (تطابق أرقامها مع الجداول). ملف `tests/fixtures/new_event.csv` جمل مكتوبة للتجربة وليست آراء حقيقية.
